# 生成

**一句话**：把镜头表翻译成某个模型的生成清单。

## 关于生成工具

**默认只写提示词。** 用户没说「你生成」，就一个字都不要执行。

### 只有一种情况要问

本工序唯一可能动工具的地方是**站 2 首帧板**（那还是生图，模型怎么选见 `sucai`）。

> 问一句：「首帧板你自己跑，还是要我代跑？要的话用哪个模型？」

### 三条硬规矩

1. **用户说只要提示词，就一个字都不要执行**
2. **用户没说模型，不许自己挑一个就开跑**
3. **不要因为「顺手更方便」就自己生成**。决定权在用户，不在你。

## 产物

写到 `<项目>/05-生成.md`：分片方案、16 槽位提示词、对账表。

写完说一句：「这一步完了。下一步**加载 `jianji`**，用《剪辑》。」

## 进门前
- `04-素材.md` 在，`素材/` 里有锁定的图，`素材/vo/` 有参考音频（走 TTS 的话）
- **读 `01-剧本.md` 文件头的「画幅」**——Wan 要写进提示词，Seedance 不写，但构图要靠它
- **读 `04-素材.md` 头部的「台词路径」**
- **先读设定集**：⑭ 表演槽位只写两样东西——**表情**（一镜一个微动作）和**身体习惯**（设定集里那一行）
- **镜头表已存在**（不是临时想的）

## 不做什么
- 不管剪辑
- 不管镜头表怎么排
- 不管素材怎么出
- **不调用任何外部 prompt 工具**，本工序自包含

> ①「用 Wan 还是 Seedance？」
> ②「Seedance 的话，2.0 还是 2.5？」
> ③ **台词路径**：去 `04-素材.md` 头部读那一行（`模型原声` / `TTS`）。**没有就问一句，问完写回去**

| | 单段上限 | 参考上限 |

| Seedance 2.0 | 15 秒 | 9 |
| Seedance 2.5 | 30 秒 | 50 |

**表里写「问用户」的，就去问。** 不知道单段上限就分片，等于闭眼裁布——超了会被截断，短了白花钱。

> 「Wan 3.0 你那边单段最长几秒？我按那个分。」

**不许猜，也不许按 Seedance 的数套过去。**

## 第 1 站：分片

- **每段里 ★ 镜头不超过 3/4**：一段 4 个分镜，最多 3 个 ★，留 1 个可省
  ——模型必吞一个分镜，全 ★ 的段一旦吞了就是硬跳
- 6 秒以上的镜头 → 拆成**两段连续分镜**（同一动作的延续，不是切镜）
- 一段只干一件事
- 相邻段要有变化轴（左→右 / 上→下 / 远→近）
- 黑场不进生成，剪辑加

---

## 第 2 站：首帧板

**不是每镜都要。** 一次生成内部的分镜天然连续，不需要静态图去锁。

只做两种：

1. **跨生成接缝**的镜头
2. **需要精确构图**的关键镜

**先列出清单，批了再做。** 每镜都做就是白花钱。

### 第 3 站 · 两家的填法差别（照抄必翻车）

| 槽位 | Wan 3.0 | Seedance 2.0 |
|---|---|---|
| 12 时间轴 | `分镜1（00:00-00:04）`，每段 **2–5 秒** | 写节拍**顺序**，时间码待验 |
| 5 参考 | **`图1` `图2`**，按上传顺序 | `@图片1`，4–5 张别用满 |
| 15 台词 | `角色说："…"` | `{…}` |

| 负向 | **有独立负向块** | 没有，否定全内嵌 |
| 画幅比 | 写 | **不写** |
| 8 光学 | 焦段感，**不写毫米** | `LENS LOCK = 47° (50mm)` |

## 第 4 站：分镜的写法

**五要素**（缺一即塌）

| 要素 | 一句话 |
|---|---|
| 镜头动作 | 一个动词：推 / 移 / 绕 / 降 / 抬 |
| 焦点落点 | 这段看哪儿 |
| 微动作 | 抬眼、拨发、眨眼；不给表演 |
| 光事件 | 这段有没有光变化 |
| 本段任务 | 这段要让观众看到什么 |

**句式轮换**（每 3–4 镜至少一个非标准句式）

跟拍式 / 转场式 / 焦点式 / 遮挡式 / 参照物式 / 主观式

> 把 10 条并排念一遍，**开头全是同一个句式就是废的**，重写。

## 第 5 站：对账

| 镜号 | 归属 | 附图 |
|---|---|---|
| S01-01 | 单切 | 无 |
| S01-02 | 第 1 次生成 · 分镜 3 | 图1, 图2 |
| S01-07 | 剪辑合成 | 无 |

「归属」只填三种：`单切` / `第N次生成 · 分镜M` / `剪辑合成`。

**填不出来的，就是漏了。** 两分钟的事，能省一场补拍。

## 第 6 站：480p 验什么

| 验 | 不验 |
|---|---|
| 分镜是不是都出现了 | 脸部细节 |
| 构图（景别、距离感） | 皮肤质感 |
| 调度（人走的位置、门的朝向） | 头发丝 |
| 运动（该自己关的门关了吗） | 镜头呼吸感 |
| 对白有没有落对位置 | 音色 |

> 480p 只回答一件事：**这段的「事」做对了没有。** 质感是 1080p 的事。
>
> **五项全过才算通过。** 过三项就上 1080p，等于把问题放大四倍再发现。

## 台词必须带音色编号

**每一句台词都要点名是谁的嗓子。**

```
✗ {沈九：「收了钱，账就平了。」}
✓ {沈九·VO-01：「收了钱，账就平了。」}
```

### 为什么

| 没编号 | 有编号 |
|---|---|
| 模型随便配一把嗓子 | 音色指向 `sucai` 那张人物卡 |
| 剪辑叠 TTS 时不知道用哪条 | 直接查 `VO-01` |
| 同一个人跨段换了嗓子，查不出 | 一对号就知道 |

### 配音走哪条路，台词写法不同

| 路线 | 台词怎么写 |
|---|---|
| **模型原声** | `{沈九·VO-01：「…」}`，编号只做记录，声音由模型出 |
| **TTS 后期** | 视频侧写 `无台词`；台词只出现在 `sucai` 的逐句 TTS 提示词里，编号对齐 |

**两条都留就是两轨人声。** 定了哪条就写哪条。

### 参考素材清单要分两类

```
**参考图（顺序即编号）**
| # | 图名 | 锁什么 |
|---|---|---|
| 1 | 沈九脸锁 | 脸型、灰衫、缺指 |

**参考音频（如果平台支持音频参考，才列）**
| # | 音名 | 对应谁 |
|---|---|---|
| 1 | VO-01 | 沈九 |
```

**平台不支持音频参考就不列**，靠台词里的 `VO-01` 做文字锚。

## 参考图：正文只写图名，编号交给脚本

> **数字错了看不出来，图名错了当场报错。**

### 文档里怎么写

每段先列清单，正文只用 `@图名`：

```
### G05 · 刀架上脖子

**参考图（顺序即编号，只列这次真传的）**
| # | 图名 | 锁什么 |
|---|---|---|
| 1 | 沈九脸锁 | 脸型、灰衫、缺指 |
| 2 | 雷震脸锁 | 方脸短须、左眉疤 |
| 3 | 雁翎刀 | 刀形、吞口 |

**提示词**
参考 @沈九脸锁 的身份，对面是 @雷震脸锁。刀是 @雁翎刀。
```

### 三条硬规矩

1. **正文禁止手写 `@图片N`** —— 只写 `@图名`
2. **清单的 # 必须 1..N 连续**，只列这一次真传的
3. **正文里的 `@图名` 必须在清单里**；清单里每一张也必须被用到

### 出稿前跑脚本

```bash
python3 scripts/refnum.py 05-生成.md           # 只检查
python3 scripts/refnum.py 05-生成.md --write   # 检查并改成 @图片N
```

它报三种错：

| 报什么 | 说明 |
|---|---|
| 清单编号不连续 | 传 2 张却编到 3 |
| 正文用了清单外的图名 | 那张图没传，或名字打错 |
| 出现手写编号 `@图片N` | 违反第 1 条 |

**报错就改文档，不许绕过脚本手写编号。**

### 为什么这么做

```
数字错了：@图片2 该指雷震，实际第 2 张是沈九全身
        → 模型把沈九的脸当雷震 → 全片三张脸，没人发现
名字错了：@雷震脸锁 不在清单里
        → 脚本当场报错
```

**把「看不出来的错」变成「一眼就报的错」。**

### 对账表也跟着改

「附图」列不写编号，写**图名**：

| 镜号 | 归属 | 参考图 |
|---|---|---|
| S1-05 / 06 | 第 2 次生成 · 分镜 1–2 | 沈九脸锁、雷震脸锁 |

## 人物白名单（不写就会长人）

**模型最爱干的事就是「填人」。** 你写「满楼的江湖人」，它会自己长出女剑客、甲胄护卫、端茶的伙计。

### 规则

每个有人的段，**关键块里必须有一句**：

> 画面里只有三个人：沈九、雷震、张崇山。**没有第四个人，没有背景食客。**

### 群像怎么写

```
✗ 满楼的人都站起来了
✓ 七个人，五个坐着两个站着，全是灰褐短打，没有女人，没有甲胄
```

**能数的才写，写不出数就先数清楚。**

### 为什么

第二集第一版：「一群人抱拳」→ 出来一个女剑客 + 两个甲胄护卫。
**设定里没这两个人，观众会以为漏看了一集。**

## 有台词的人必须在画面里

写了 `{阿福：「那接下来怎么办？」}`，**阿福就必须在这一段的分镜里出现过**。

只有声音没有人，观众会问「谁在说话」。

| 情况 | 怎么办 |
|---|---|
| 说话人在本段 | 分镜里至少给他一个镜头 |
| 说话人在画外 | 台词前显式写「画外」，且前一段他出现过 |
| 说话人从没出现 | **不要写这句台词** |

## 分镜数核对（生成之后）

**声明 4 个分镜，模型可能只做 3 个。**

少一个分镜，剪的时候就是一次跳跃——观众说不出哪里不对，但会觉得「少了点什么」。

对账表加两列：

| 段 | 声明分镜 | 实际分镜 | 缺哪个 |
|---|---|---|---|
| G02 | 4 | 3 | 「停步回头」 |

**缺的补法**：单独生成那一个分镜，或从相邻段挪用，或改镜头表承认少一镜。

**不许不记。** 不记就等于默认它不存在。

## 三条对照检查（写完之后必做）

### ① 降级检查：镜头表的主体，不许变成环境

拿镜头表的「画面」列，逐行对提示词的分镜：

```
镜头表：酒壶 / 楼梯        ← 两个主体
提示词：端执壶「从楼梯口」走过来  ← 楼梯降级成地点了
```

**「画面」列里的名词，必须在分镜里当主语出现一次。**
只是背景里"有"，等于没拍。

### ② 空间锚检查：同一空间跨两段，必须共享同一套空间描述

同一个门、同一间屋、同一条街，如果出现在两次生成里：

- 两段的**空间图（槽位 6）必须逐字相同**
- 两段都要写清：**门在哪、光从哪来、地面什么材质、人在门的哪一侧**

做不到，就会「出门—又出门」——每一段都把门口重新建一遍。

### ③ 位置检查：关键道具写「在哪」，不写「在做什么」

```
✗ 刀架在脖子上
✓ 刀刃贴着他左颈，刀背朝上，刀柄在他右肩前，刀尖出画左
```

```
✗ 按下手印
✓ 右手按进红泥，掌心朝下，小指那一块是空的
```

**动作＋相对位置**，缺一半模型就会自由发挥。


## 闸被跳过时，必须登记

用户催进度（「直接生成」「别问了」「你剪吧」）时，**闸可以被跳过，但必须留痕**：

```
⏭ 跳过：首帧板 / 480p
   代价：（写清会因为这一跳丢掉什么）
   决定人：用户
```

**写在本工序产物文件的「跳过记录」一节里**——不是写进别人的文件，也不是只在对话里说一句。

**三件事缺一不可**：跳过了什么 / 代价是什么 / 谁决定的。

**没有登记的跳过 = 事故。** 因为下一轮没人知道哪里漏了。

## 出门判定

- [ ] 每个镜号都落到「单切 / 某次分镜 / 剪辑合成」？
- [ ] 六个承重墙（3·4·6·8·14·16）都在吗？
- [ ] 10 条分镜开头不是同一个句式？
- [ ] 每段有「本段任务」？
- [ ] 首帧板只做了跨接缝和关键构图？
- [ ] **跑过 `refnum.py` 且没报错**？
- [ ] **降级检查过**：镜头表「画面」列的名词都在分镜里当过主语？
- [ ] **空间锚检查过**：跨两段的同一空间，空间图逐字一致？
- [ ] **位置检查过**：刀、手印、账本这类关键道具，写的是位置不是动作？
- [ ] 480p 五项全过？

**逐条打勾，列出没通过的，停下等人确认。**

## 坑

- 直接 1080p → 废一条的代价是整段
- 漏镜 → 靠对账才发现，不是靠记性
- 分镜只写「画面内容」不写镜头动作 → 模型自己决定怎么动
- 照抄另一家口径 → 两家的规矩正好相反
- 首帧板每镜都做 → 白做几十张图
- 把镜头表的主体降级成背景 → 观众看不到该看的东西（楼梯变凳子）
- 同一空间跨段不写一样的空间图 → 出门又出门
- 关键道具只写动作不写位置 → 刀的位置每段都不一样
- 有台词的人不在画面里 → 观众不知道谁在说话
