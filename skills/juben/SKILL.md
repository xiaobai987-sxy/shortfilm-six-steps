# 剧本

**一句话**：把主题变成内核、正典、分场。

## 这套流程只做一件事

**画面必须由视频模型生成。这是唯一的出片方式。**

| 要什么 | 走哪 |
|---|---|
| 视频模型生成画面（Wan / Seedance） | **本工序** |
| 网页动效 / 代码合成 / 模板套用 | **不在本范围，直接说明，别硬做** |

用户的话听起来像「宣传片 / 动效片 / 网页动画」时，先确认一句：

> 「画面你想让**视频模型生成**，还是用 **HTML 动效拼**？这套流程只做前者。」

**别猜。** 猜错的代价是整条流程白跑——而且会一路写到 TTS 脚本和 BRIEF 上去。

## 启用 / 不启用

> 这一节是硬约束。**不是建议。**

| | |
|---|---|
| ✅ **加载** | 本工序 `juben`（需要上游产物就直接读文件，不用加载别的 skill） |
| ✅ **画面来源** | **视频模型生成**（Wan 3.0 / Seedance 2.0·2.5）——**这是本套唯一的出片方式** |
| ❌ **不用代码合成** | HTML / CSS / Canvas / SVG / Remotion / After Effects / 截图拼接 / 模板套用——**画面一律不许这么做** |
| ✅ **用工具** | 读文件 · 写文件（**只写 01-剧本.md**） |
| ❌ **不加载** | `hyperframes` 全家桶（core/animation/cli/studio/creative/keyframes/registry/audio）、`general-video`、`motion-graphics`、`slideshow`、`faceless-explainer`、`product-launch-video`、`media-use`、`video-shotcraft`、`remotion-*` |
| ❌ **不跑命令** | `npx hyperframes …`、`pnpm hyperframes …`、`hyperframes init`、`hyperframes render`、`remotion …`、任何渲染 / 发布 / 上传命令 |
| ❌ **不建结构** | 不建 `.hyperframes/`、不建 `compositions/`、不写 `index.html`、不写 `package.json`、不跑 `init` |
| ❌ **不碰接口** | 不生图、不生视频、不跑 TTS |
| ❌ **不写别的文件** | 除 `01-剧本.md` 外，不写任何文件 |

### 为什么写这么死

`hyperframes` 自称「任何视频请求的强制入口」，它全家桶加起来二十多个 skill、
一套 CLI、一套项目脚手架。**一旦它启动，就会建目录、写 `index.html`、跑渲染**——
那时候再喊停，已经写了一堆不该有的东西。

**所以不是「用错了再改」，是「压根不许启动」。**

> **这一节只能约束本工序自己。** 拦不住 `hyperframes` 被别处触发——
> 那要看它的 description 和项目配置。真要压死，在项目级 `CLAUDE.md` 里写一次，或者在这个项目里禁用它。


### 只做一件事

本工序只负责出 `01-剧本.md` 这一份东西。
**不合成、不渲染、不配乐、不发布。** 那些都不在这里。

## 产物

写到 `<项目>/01-剧本.md`，**文件头要有两行规格**：

```
画幅：16:9
时长：约 4 分钟
```

这两行后面每一步都要读——**画幅决定距离感，距离感决定镜头表**。

写完说一句：「这一步完了。下一步**加载 `dingxi`**，用《定戏》，从 S1 开始。」

## 进门前
- 访谈走完，**用户说「OK」**（不是问完就写）
- 有一个主题，哪怕只有两个字

## 不做什么
- 不排镜头（→《镜头表》）
- 不定这一场怎么讲（→《定戏》）
- 不管系列世界观——**只管一部戏**
- 不管**分片**和**每段时长上限**（但这一场大概多少秒要估）、不管模型、不管提示词

## 六站（0–5），顺序不能跳

0. **访谈** —— 见下，**聊到用户说 OK** 才往下
1. **一句话内核** —— 必须一句。两句就是没有。
2. **设定集** —— 世界 / 人物卡 / 关系 / 禁忌 / 语言。**人物每人 7 行，五行不够。**
3. **规则的可拍化** —— 拆成「拍得出来的」和「拍不出来的」。
4. **分场** —— 每场一句话，且「这一场只做一件事」。场数由总时长定（见下）
5. **时长估算** —— 每场大概多少秒，加起来对不对。

## 第 0 站：访谈 —— 聊到用户说 OK

**不是问八个问题就完。目标是把这个世界捕捉到没有缝。**

### 起手三批，然后循环

| 批 | 问什么 |
|---|---|
| 一 · 故事 | 你脑子里**最先出现的画面**是什么？（先要画面不要主题）· 里面是谁、几岁、为什么偏偏是他 · 观众看完什么感觉 |
| 二 · 形状 | 最想让人记住**哪一刻** · 有没有参考（片名/导演/某张照片都行）· 多长 |
| 三 · 规格 | **画幅**：16:9 / 9:16 / 2.35:1 · 有没有不能出现的东西 |

### 三批问完，开始循环

**不要以为问完就该写了。** 三批只是把骨架搭起来，肉还没长。

循环里做三件事：

1. **复述**：把你理解的世界讲一遍，问他「哪里不对」
2. **补缝**：专挑薄弱处问
   - 这条规则谁会去破坏？破坏了会怎样？
   - 他怕什么？最不想要什么？
   - 钱从哪来、谁在管、出事谁负责？
   - 故事开始前，这个人上一分钟在干什么？
3. **追问**：他说「就是那种感觉」的时候，问「哪一种？说三种，我猜哪个最像」

**一直聊到他说「ok，可以了」。**

### 什么时候算够

- 任何一个问题，你不问他就知道答案
- 你自己在脑子里把这几个场演一遍，**没有卡住的地方**
- 他复述不出新东西了

这三个都满足了，再往下走。

### 访谈三条规矩

- **答不上来的别替他编。** 说「可以先留白」，然后继续
- **画面优先于概念。** 只给主题就追问：「那你能看见什么？」
- **参考比形容词有用。** 「像《X》那种」比「要有电影感」信息量大十倍

### 一句警告

**这是整条线最关键的一步。**

剧本糊了，后面五个工序都在给一个糊的东西做精装修——而且每一道工序都会让它更糊一点。

**宁可在这里多聊半小时，也别急着往下走。**

## 第 2 站 · 设定集（不是五行）

**后面四个工序全部靠它活。** 设定集薄一寸，定戏就只能猜，素材就只能编，生成就只能漂。

### 一、世界（4 行）

| 行 | 写什么 | 例 |
|---|---|---|
| 时代 | 哪朝哪代，或者架空到什么程度 | 架空南边水乡县城 |
| 地方 | 一个具体的地方，不是「古代」 | 临水县城，望江楼二楼 |
| 规矩 | 这个世界怎么运转，**一条能推翻的规则** | 江湖的命记在沈家账上，不收钱只收人 |
| 天气 | 具体到这一刻 | 雨天，午后 |

**「规矩」这一行是全片的地基。** 写不出「谁能推翻它」，这个规矩就是装饰。

### 二、人物卡（每人 7 行）

```
外形     灰布长衫，右手缺一根小指
身份     四十八，沈家第七代账房
想要     （这一场他要拿到什么）
怕       （他最不想发生什么）
藏       （他绝不说出口的是什么）
说话方式 短句，不解释，句末不上扬
身体习惯 想事情的时候，右手的拇指会摸断指的截面
```

**七行缺一不可。**

| 行 | 少了会怎样 |
|---|---|
| 想要 | 定戏没法写「他为什么这么干」 |
| 怕 | 制造不了紧张 |
| 藏 | 观众没有「信息差」可用 |
| 说话方式 | 配音只能靠猜，台词谁念都一样 |
| 身体习惯 | 表演只能给「表情」，给不了「动作」 |

**「身体习惯」那一行最值钱**——它是 AI 唯一能稳定执行的人物内部描写。表情它会漂，一个反复出现的小动作不会。

### 三、关系（一张小表）

| 谁 | 对谁 | 什么账 |
|---|---|---|
| 雷震 | 沈九 | 三年前他师父欠七条命，他不知道 |
| 张崇山 | 沈家 | 三十年欠一条命 |

**关系不写清，群戏就是一堆陌生人站着。**

### 四、禁忌（片子里绝不出现）

写 2–3 条。例：账本不能烧；不给正脸大特写；不出现血。

### 五、语言

称呼怎么叫（「沈先生」不是「沈九」）、有没有口头禅、句子多长。

**这一条决定配音的断句，也决定字幕的长度。**

## 第 4.5 站 · 台词全录（必须真的做出来）

**分场之后、出门之前，把这一集所有台词按出场顺序抄一遍。**

```
1. 沈九：跪下倒。
2. 雷震：……
```

**必须是完整的一份，不是散在分场里的引文。** 后面三个工序都只认这一份。

改台词：**回来改这一份**，然后让下游重读。别在别处改字。

## 场数怎么定

| 总时长 | 场数参考 |
|---|---|
| 60–90 秒 | 3–4 场 |
| 90–150 秒 | 5–6 场 |
| 150–240 秒 | 6–8 场 |

**6 场是《糖》那支 4 分钟片子的数，不是规矩。** 场数服从时长和「每场只干一件事」。

## 台词只有一份，就在这份文件里

**`01-剧本.md` 的「台词全录」是全片台词的唯一真源。**

| 下游 | 它做什么 | 它不许做什么 |
|---|---|---|
| `sucai` | 按这句写 TTS 提示词 | 不许改字、不许合并、不许拆句 |
| `shengcheng` | 按这句写进 `{}`，加 `VO-0N` | 不许改字 |
| `jianji` | 用 whisper 核对**说的和这句一不一样** | 不许「顺一下」 |

**改台词只有一个地方：回来改这份文件，然后通知下游重读。**

在别处改一个字，后面三处全对不上。

## 第 3 站是关键

规则里**拍不出来**的那半句，必须找到一个具体镜头承载。

例：「每年摆一碗糖，大人都拿过，但都不记得」——
前半句能拍，后半句拍不出来，它靠妈妈那句「我忘了」承载。

**找不到承载镜头的规则，这条规则不存在。**


## 闸被跳过时，必须登记

用户催进度（「直接生成」「别问了」「你剪吧」）时，**闸可以被跳过，但必须留痕**：

```
⏭ 跳过：访谈没问完就开写
   代价：（写清会因为这一跳丢掉什么）
   决定人：用户
```

**写在本工序产物文件的「跳过记录」一节里**——不是写进别人的文件，也不是只在对话里说一句。

**三件事缺一不可**：跳过了什么 / 代价是什么 / 谁决定的。

**没有登记的跳过 = 事故。** 因为下一轮没人知道哪里漏了。

## 出门判定

- [ ] 能用一句话说出「观众出去时知道什么」？
- [ ] **每个人物卡七行都填了**（想要 / 怕 / 藏 / 说话方式 / 身体习惯 尤其）？
- [ ] **关系表**写了谁欠谁？
- [ ] **禁忌** 2–3 条？
- [ ] 每一场能用一句话说出「这一场只做一件事」？
- [ ] 拍不出来的那半句，有承载镜头了吗？
- [ ] 场次没超过 6 场？

**逐条打勾，列出没通过的，停下等人确认。人不在，不许往下走。**

## 想不出来就如实说，不硬凑

写不出内核就写不出，别用「一部关于失去的电影」糊过去。
硬凑出来的内核，后面每一场都在为它编。

## 坑

- 边写边拆 → 每个镜头都在为没写完的剧情服务
- 内核写成两句 → 等于没有
- 规则太抽象 → 必须落到一个物件或一句台词
- 人物只写外形 → 后面四个工序全在猜他是什么人
- 忘了写「身体习惯」→ 表演只能给表情，而表情最容易漂
- 场次超 6 → 4 分钟装不下
