# 剪辑

**一句话**：能救的绝不要重摇。

## 启用 / 不启用

| | |
|---|---|

## 第 1 站 · 素材体检

每段素材填一行：

| 段 | 原长 | 可用区间 | 坏帧 | 台词核验 |
|---|---|---|---|---|
| G03 | 11.1s | 0–7.4 | 7.4s 后画面 180° 翻转 | 齐 |

**三件事必须做：**

1. **抽帧两遍**（见下节）
2. **台词在不在素材里** —— 抽音轨 → `whisper` 转写 → 和剧本逐句对
3. **有没有「烤进画面」的对白** —— `showspectrumpic` 画频谱，看声音是不是烧在轨道里

> **模型漏词、改词、多说一句，都在这一步发现。** 到剪辑台上才发现，只能重摇。

---

## 抽帧要两遍，不是一遍

**「至少 6 帧」是错的下限。** 10 秒的片段 6 帧 = 1.7 秒一帧，看不出切点。

### 第一遍 · 粗扫（找坏帧）

```
fps = 8 / 时长   →   -vf "fps=$fps,scale=440:-1,tile=4x2"
```

只回答一件事：**这段有没有明显坏帧**（翻转、糊掉、人漂、黑场）。

### 第二遍 · 切点密集（定刀口）

每个候选切点前后各 1.5 秒，`fps=5~6` 抽 **15–20 帧**：

```
ffmpeg -ss <切点-1.5> -t 3 -vf "fps=6,tile=4x5"
```

只回答一件事：**这一刀落在第几帧。**

**不做第二遍，切点就是猜的。**

## 第 2 站 · 粗剪

### 先看话说完没有，再看动作收口

**切点必须落在语音的静默里。** 这是硬约束，不是偏好。

```
动作收口在 9.2 秒
台词「…抄了七份送到七个不在这个祠堂里的人手里」说到 11.8 秒
→ 切 9.2 就是切在「抄」字中间，后面 2.6 秒全丢
```

**动作和台词冲突时，让画面多留，不要让话断。**

留多少：**最少 0.2 秒静默**，理想 0.3–0.5 秒。

### 对着哪条音轨查

| 台词路径 | 查什么 |
|---|---|
| **模型原声** | 对成片转写（声音就在画面里） |
| **TTS** | **对 TTS 音轨转写**，不是对成片——视频里写的是「无台词」，成片转写出来是空的 |

TTS 路线把配音轨单独导一条出来，用 `cutcheck.py` 查那一份。

### 怎么找到静默

先转写拿词级时间码，再在词与词之间找空隙：

```bash
python3 scripts/cutcheck.py 成片.mp4 --cuts 10.0,18.0,28.0,37.2
```

它逐刀判三种：

| 判定 | 意思 |
|---|---|
| ❌ 切在词中 | 一个字被切成两半 |
| ⚠️ 紧贴词尾 | 词刚结束 0.15 秒内，容易听出「噎住」 |
| ✅ 静默 | 落在这句话和下一句之间 |

**有 ❌ 或 ⚠️ 就不许定稿。** 它同时会给出最近的静默区间，照着挪。

### 按动作切，不按秒切

模型的分镜会漂 1–3 秒。按提示词里的时间码切，一定错位。

**找动作**：「她回头看门」「门开始动」「她冲进平台急停」——从动作开始的地方切。

### 先用低分辨率

```
854×480 或 720p —— 只用来判节奏，不看质感
```

**粗剪阶段不上 1080p。** 一段错了，重出便宜十倍。

### 时间线写清楚

| 序 | 段 | 用的区间 | 成片位置 | 时长 |
|---|---|---|---|---|
| 1 | G01 | 0.3–10.4 | 00:00–00:10.1 | 10.1 |

## 重复动作检查（看完全片再做一遍）

**同一个动作，在全片出现几次？**

| 动作 | 设计几次 | 实际几次 |
|---|---|---|
| 出门 / 离开门口 | 1 | 4 |
| 起身 | 1 | 2 |
| 举刀 | 2 | 3 |

**超过设计次数，就是"每段各自建立了一遍同一个动作"**——这是跨段生成的通病。

修法：**保留最早一次和最后一次，中间的重叠段剪掉。**

## 第 3 站 · 接缝检查（每一刀看三样）

**这是最容易被跳过、也最容易露馅的一步。**

| 看什么 | 出错的表现 | 怎么修 |
|---|---|---|
| **画面跳变** | 同一空间光变了、人换了衣服 | 剪掉几帧，或用前一镜的尾帧接 |
| **屏幕方向** | 上一镜朝右，下一镜朝左 | 换刀，或翻面（慎） |
| **声音连续** | 上一段房间声和下一段不一样 | 铺一层连续的环境底噪压过去 |

**每个接缝都抽帧看过再说。** 全片 12 刀，就是 12 次。

## 第 4 站 · 声音

### 响度必须先对齐

12 段来自 12 次生成，**响度一定不一样**。不对齐，观众会一直伸手调音量。

```
ffmpeg -i in.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:v copy out.mp4
```

逐段过一遍，再拼。

### 先量一下音色有没有变

选「模型原声」的片子，**每段是各自配的音**，很容易同一个人换了几把嗓子。

```bash
python3 scripts/voicecheck.py 素材目录/ --glob "*.mp4"
```

它报每段人声的**基频中位数**，以及相对中位的偏差：

```
中位 129 Hz · 最大偏差 103.9%  ⚠️ 超过 12%，可能换人了
```

**注意**：它测的是「这一段所有人声的整体音高」，不是单个人。所以：

- 偏差小 → 基本没问题
- 偏差**极大**（超过 50%）→ 这一段的主导声音和别人差一个性别，**一定有角色被换了嗓子**
- 十几二十个点的偏差 → 可能只是这段谁说话多，要**听一遍**

**它是探针，不是判决。** 报异常就回去听，不要拿数字当结论。

### 台词两条路，选一条

| 路 | 怎么做 |
|---|---|
| **用模型原声** | 直接用，但要先用 whisper 核对台词对不对 |
| **换 TTS** | 静音原声，铺 `sucai` 那套逐句 TTS，按时间码对齐 |

**不许两条一起留**——那就是两个人说话。

### 环境铺底

拼接处一定有声场跳变。铺一层**全天候环境底噪**（雨、室内嗡鸣、街声）压过去，
比逐段修混响便宜得多。

## 字幕：做不做要问一句

**流程里默认不问，是个漏洞。** 有台词的片子，交付前必须明确一次：

> 「要字幕吗？要的话是硬字幕（烧进画面）还是软字幕（srt）？」

| 选项 | 什么时候用 |
|---|---|
| 不烧字幕 | 投稿平台自带字幕 / 纯海外发行 |
| 硬字幕 | 抖音、B站、视频号（多数情况） |
| 软字幕 srt | 需要多语言 / 需要后期改字 |

**要做的话，用 whisper 的时间码出 srt，不要手打。**

```bash
python3 scripts/cutcheck.py 成片.mp4 --cuts 0   # 顺带拿到词级时间码
```

## 救火：三级，不许跳

```
① 剪辑能救吗？      剪掉 / 换刀 / 不给特写
② 能配音救吗？      换音轨 / 加旁白
③ 都不行才重摇
```

### 什么才算「必须重摇」

**三条同时满足**，少一条都不算：

1. **规则被破坏**（全片攒的那几条，比如「不给正脸」）
2. **剪不掉**（这一镜本身就是那一处，没别的素材可替）
3. **影响理解**（观众会看不懂，不是只是不好看）

只满足一两条的，都是「剪一下」的事。

## 出门判定

- [ ] 每段素材都做过两遍抽帧？
- [ ] 台词逐句核验过（whisper）？
- [ ] **每一个接缝**都抽帧看过？
- [ ] **跑过 `cutcheck.py`，没有一刀切在词里？**
- [ ] **问过字幕要不要，要的话出了没有？**
- [ ] **量过音色**（`voicecheck.py`），异常段回去听过？
- [ ] 响度对齐了吗？
- [ ] 台词只留了一条路（原声 / TTS）？
- [ ] 末帧确认是真黑？
- [ ] 重摇清单里每一条，三条判据都满足？

**逐条打勾，列出没通过的，停下等人确认。**

**想不出来就如实说，不硬凑。** 说不出这一刀为什么在，就说明它不该在。

## 坑

- 按时间码切 → 必错位
- 只按动作收口切，不看台词 → 话没说完就跳下一镜（最常犯）
- 只做 6 帧粗扫就下刀 → 切点全是猜的
- 一发现问题就重摇 → 本来剪一下就好
- 音效音乐提前铺 → 会盖住节奏判断
- 只看首帧判断 → 正脸可能到第 7 帧才出现
- 12 段不调响度直接拼 → 观众一直在调音量
- 重摇清单写「感觉不太好」→ 那是没判据，等于没清单
- 不数重复动作 → 出门三四次，观众以为他犹豫了
