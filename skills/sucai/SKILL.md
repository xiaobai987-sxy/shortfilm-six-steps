# 素材

**一句话**：先变成锁定的资产，再谈生成。

## 关于生成工具

**默认只写提示词。**

但如果这个会话里有可用的生成工具：

### 要问两句，不是一句

1. **「要不要我用工具生？」**
2. **「用哪个模型？」** ← 这一句不能省

### 生图模型怎么选（要摆给用户看）

| 模型 | 适合什么 |
|---|---|
| **gemini-3.1-pro**（Nano Banana Pro） | 写实最稳：脸、皮肤、材质。**定妆照和道具板首选** |
| **gemini-3.8-flash** | 快、便宜，适合试错和气氛小样 |
| **gpt-image-2 / 2.5** | 画面里有文字、排版、图形时强；纯电影感偏弱 |

**不同的东西可以用不同的模型**：定妆照用 Nano Banana Pro，气氛图用 flash 试。

### 问话模板

> 「要生的话用哪个模型——Nano Banana Pro（写实最稳）、flash（快、便宜试错），
> 还是 gpt-image（有文字时用）？还是只要提示词，图你自己跑？」

### 用户选「只要提示词」时，必须说清代价

**这句话不能省：**

> 「只给提示词的话，**人物会飘**——每次生成都会重新猜一张脸。
> 想稳住，至少把主角的脸锁做出来（一张就够）。」

| 做法 | 人物一致性 |
|---|---|
| 全用提示词 | **必飘**，1 段一张脸 |
| 至少做主角脸锁（1 张） | 大幅改善 |
| 全部脸锁 + 服装 | 稳 |

**只做一张脸锁的成本，远低于重摇十二条。**

### 三条硬规矩

1. **用户说只要提示词，就一个字都不要执行**
2. **用户没说模型，不许自己挑一个就开跑**
3. **不要因为「顺手更方便」就自己生成**。决定权在用户，不在你。

## 产物

写到 `<项目>/04-素材.md`：**每条素材一段提示词**，加上音色卡。

**图不由本工序自动生成。** 默认只交提示词，用户自己跑，跑完放 `<项目>/素材/`，回来告诉你哪几张过了。

如果会话里恰好有生图工具，可以**问一句要不要代跑**（见上），但默认动作永远是「交提示词」。

写完说一句：「这一步完了。下一步**加载 `shengcheng`**，用《生成》。」

## 进门前
- 镜头表已锁
- 知道有几套服装、几处场景、几个人说话
- **先读 `01-剧本.md` 的设定集**：外形那一行给脸锁，说话方式那一行给音色，身体习惯那一行给表演

## 不做什么
- 不管首帧板（→《生成》，因为要先知道怎么分片）
- 不管提示词、不管生成
- 不管镜头怎么排
- 整段口播配音、统一间隙、字幕对齐 → 不归这里

## 三站，顺序不能跳

| 站 | 做什么 | 为什么这个顺序 |
|---|---|---|
| 1 | **人物卡**：脸锁 → 服装 → 三面图 → **声音** | 脸锁和声音**同时出**，一张卡两半 |
| 2 | **道具**：每件正 / 45° / 细节 | 道具漂＝叙事漂 |
| 3 | **场景**：每处 1–2 张 | 空间接不上就跨场断 |

### 为什么声音必须在第 1 站出

**人是一个整体。** 你锁了沈九的脸，不锁他的声音，生成时脸是那张、嗓子是随机——这个人只锁了一半。

而且**编号必须成对**：

```
CH-01  沈九 · 脸锁          VO-01  沈九 · 音色
CH-02  雷震 · 脸锁          VO-02  雷震 · 音色
```

**CH-0N 和 VO-0N 永远同号。** 后面每一句台词、每一次生成、每一刀剪辑，都靠这个号对回同一个人。

**声音不是收尾，是人物卡的另外一半。**

## 人物卡 · 声音这一半

> 一张人物卡 = 脸锁（图）+ 音色卡（字）+ 参考音频（8–12 秒）+ 逐句 TTS 提示词。
> **四件一起交，缺一件这张卡就是半成品。**

**只写「音色卡」是不够的**——那是一段描述，跑不出声音。

### 音色只有两条路，**在本工序定下来**

这个决定只在这里做一次。`shengcheng` 会读这里的结果，不再问第二遍。

> 在 `04-素材.md` 的头部写一行：`台词路径：模型原声` 或 `台词路径：TTS`

### 两条路

| 路 | 你得到 | 代价 |
|---|---|---|
| **模型原声**（视频模型自己配） | 省事，口型自动对 | **音色不可控**——每段各配一把嗓子，跨段不一致 |
| **TTS 后期配** | 音色锁死，全片一把 | 要做参考音频 + 逐句提示词 + 对时间码 |

**选了模型原声，就不要在判定里勾「有参考音频」——那是自欺。**

音色卡在这种情况下只是**描述一份你拿不到的声音**，写它有意义，但**不等于锁住了**。

### ① 音色卡（每人一条）

| 项 | 写什么 |
|---|---|
| 音色 | 低频/中低/中高 + 干湿 + 有没有沙 |
| 口音 | 地域 + 是不是普通话 |
| 语速 | 快慢 + 习惯性停顿在哪 |
| 发声状态 | 距离、空间、有没有隔着东西 |

### 先划范围：只做关键主角

**不要给每个开口的人都写逐句提示词。** 铺开会写一堆没人用的东西。

谁算关键主角——**满足任意两条**：

- 台词超过 3 句
- 跨 2 场以上出现
- 片子的情绪落点在他身上

**通常只有 1–2 个人。** 其他人：

| 类型 | 给什么 |
|---|---|
| 关键主角 | 音色卡 + **逐句 TTS 提示词** + 参考音频 |
| 配角（台词 1–2 句） | 一行音色描述就够，不写逐句 |
| 群杂、背景人声 | 不写，交给现场音效 |

### ② 逐句 TTS 提示词（**这才是能直接跑的东西，只给关键主角**）

**一句台词一条，不要合并。** 每条长这样：

```
【角色】沈九
【文本】「我知道。」
【音色】三十出头男声，中低偏干，气声轻，不亮
【情绪】平静。不是狠，是在算账
【语速】慢，句末压住不上扬
【停顿】「我」和「知道」之间停半拍
【口音】北方普通话，轻微齿音
【不要】不要用力，不要咬牙切齿，不要配音腔，不要气声过重
```

规则：

- **文本原样抄，不改一个字**（改字＝改了表演）
- **情绪写到具体动作**：「平静，像在报数」，不写「严肃」
- **停顿要标位置**，不写「适当停顿」
- **末尾必写「不要」**：AI 配音最容易犯的三件事——用力、拖腔、字正腔圆

### ③ 参考音频

每人一段 **8–12 秒**，同一间屋子、同一混响、不配乐。
后面所有句子都用它当音色锚——**换一条参考，人就换了**。

### 配音也要问模型

跟生图一样，**要问两句**：

> 「配音要不要我生成？用哪个 TTS——qwen-tts / MiniMax / 豆包 / 别的？
> 还是只要提示词，你自己跑？」

**不知道有哪些就先探测一遍列出来**，别自己挑一个。

## 先提案，后出图

每件素材先用一句话写出来（它是什么、多大、什么材质），**批了再生成**。
这是两道花钱的闸之一。

## 三条锁

同光源 / 同画风 / 同比例尺

角色表不是图集，是**标尺**。标尺歪了，量什么都是错的。

## 写提示词的四条

- 正向说满，负向 ≤ 1/3
- 每个形容词后跟 **3 个能指认的物证**（毛孔、起球、锈迹这种）
- 只量化模型能执行的量：不写 `18%`、`f/1.8`、`85mm`
- 人物板和道具板：**中性灰背景 + 平光 + 无阴影**，光不烤进图里


## 闸被跳过时，必须登记

用户催进度（「直接生成」「别问了」「你剪吧」）时，**闸可以被跳过，但必须留痕**：

```
⏭ 跳过：人物卡四件不齐
   代价：（写清会因为这一跳丢掉什么）
   决定人：用户
```

**写在本工序产物文件的「跳过记录」一节里**——不是写进别人的文件，也不是只在对话里说一句。

**三件事缺一不可**：跳过了什么 / 代价是什么 / 谁决定的。

**没有登记的跳过 = 事故。** 因为下一轮没人知道哪里漏了。

## 门禁：人物卡四件不齐，不许进生成

**按台词路径分支查**，别一刀切。

| 件 | TTS 路线 | 模型原声路线 |
|---|---|---|
| 脸锁图 `素材/CH-0N.png` | 必须 | 必须 |
| 音色卡（四行） | 必须 | 必须 |
| **参考音频 `素材/vo/VO-0N.wav`** | **必须** | **不需要**（音色由模型出，本来就不受控） |
| 逐句 TTS 提示词 | 必须 | 不需要 |

**原声路线不要生成 wav 再放着**——那是白做，也查不出任何问题。

**但音色卡和 VO 编号原声路线也必须留。** 剪辑阶段 `voicecheck.py` 报「这段换人了」，靠的就是这个号去对是哪个角色。

### 每个开口的人都要有 VO 编号

不止关键主角。

| 角色 | 音色卡 | 逐句 TTS | VO 编号 |
|---|---|---|---|
| 关键主角（1–2 人） | 完整四行 | 有（TTS 路线） | 有 |
| 配角（1–2 句） | 一行够 | 无 | **必须有** |
| 群杂 | 不写 | 无 | **必须有**（`VO-90` 这类） |

**没有编号，`shengcheng` 就写不出 `{某甲·VO-??：「…」}`，`jianji` 也对不回来。**

## 出门判定

- [ ] 道具都有视图？（对着镜头表扫一遍所有物件）
- [ ] 人脸参考是**单独一张大头照**，不是三视图？
- [ ] **`素材/vo/` 里真的有 wav？**——`ls 素材/vo/` 能列出来才算过。
      **不是"写了音色卡"，是文件存在。** 写了没生成＝没做。
- [ ] 所有板同光源、同画风、同比例尺？

**逐条打勾，列出没通过的，停下等人确认。**

## 坑

- 只做人物不做道具 → 碗换三个、糖变彩色、相框样式不统一
- 三视图当人脸参考 → 多角度可能被识别成多个主体（**未验证**）
- 音色等生成完再做 → 两次生成不是同一个人的声音
